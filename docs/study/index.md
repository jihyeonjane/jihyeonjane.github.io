# Study

유튜브 채널 [코딩하는 아키텍트](https://www.youtube.com/@codingpe) 영상으로 진행하는 개인 스터디 기록입니다.

전체 영상을 다 보는 대신, **데이터 엔지니어링과 데이터 플랫폼(툴) 설계에 도움이 되는 영상만 선별**해서 커리큘럼으로 만들었습니다.

## 스터디 방식

1. 커리큘럼 순서대로 영상 시청
2. 모르는 개념은 파고들어서 이해 (질문 → 답 정리)
3. 영상 요약이 아니라 **"내가 몰랐던 것 + 데이터 엔지니어링에 어떻게 적용되나"** 중심으로 글 작성
4. 정리한 글은 각 커리큘럼 표의 '정리' 칸에 링크
