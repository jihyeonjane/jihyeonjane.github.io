## 제외한 영상과 이유

- **리더십 시리즈** (팀 갈등, 일정 리스크, 동기부여 등 5편) — 아키텍처 지식 목표와 무관
- **멤버십 전용 영상 4편** — 공개판이 있는 경우(커넥션 풀, Redis QPS) 공개판으로 대체함
- **연속재생 몰아보기 5편** — 개별 영상과 중복
- **쿠폰 발급 시스템 시리즈 4편** — 좋은 사례지만 티켓 예매 사례와 설계 과정이 겹침. 사례 연구를 더 원하면 [1편](https://youtu.be/--bwuk_R12E)부터
- **프론트엔드 계열** (Pre-rendering, htmx, CDN) — 지금 목표와 거리
- **평가 방법론** (ATAM, ISO 25010) — 설계 경험이 쌓인 뒤에 볼 것
- **JWT 보안 시연 2편** — 필요해지면 개념 장착 커리큘럼의 JWT 영상 이후에
